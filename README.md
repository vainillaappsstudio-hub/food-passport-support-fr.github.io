# Food Passport — Assistance

Bienvenue sur la page d'assistance de Food Passport. Vous trouverez ici les réponses aux questions fréquentes et les moyens d'obtenir de l'aide.

## À propos de Food Passport

Food Passport vous permet de marquer et d'enregistrer les plats que vous avez mangés et de créer des marqueurs alimentaires pour construire votre parcours culinaire personnel. Suivez vos aventures gastronomiques, découvrez de nouvelles saveurs et gardez un souvenir de chaque repas mémorable.

## Questions Fréquentes

### Ai-je besoin d'un compte pour utiliser Food Passport ?

Non. Vous pouvez utiliser toutes les fonctionnalités principales de Food Passport sans créer de compte. Vos données sont stockées localement sur votre appareil.

### Où sont stockées mes données ?

Vos plats enregistrés, marqueurs alimentaires, préférences et paramètres sont stockés localement sur votre appareil. Selon les paramètres de votre appareil, certaines données peuvent également être incluses dans les sauvegardes système fournies par Google ou Apple.

### L'application affiche-t-elle des publicités ?

La version gratuite de Food Passport peut afficher des publicités via Google AdMob. La version premium est entièrement sans publicité.

### Comment supprimer les publicités ?

Vous pouvez passer à la version premium de Food Passport via l'option d'achat intégré pour profiter d'une expérience sans publicité.

### Puis-je supprimer mes données ?

Oui. Vous pouvez supprimer votre contenu enregistré directement dans l'application. Vous pouvez également désinstaller l'application pour supprimer toutes les données stockées localement de votre appareil.

### Mes données sont-elles partagées avec des tiers ?

Food Passport ne vend pas vos informations personnelles. Certaines informations peuvent être partagées avec des services tiers (tels que les fournisseurs de publicité ou de cartes) uniquement pour assurer le fonctionnement de l'application. Consultez notre Politique de Confidentialité pour tous les détails.

## Dépannage

### L'application ne fonctionne pas correctement

Essayez les étapes suivantes :

1. Assurez-vous d'avoir la dernière version de Food Passport installée.
2. Redémarrez l'application.
3. Redémarrez votre appareil.
4. Si le problème persiste, essayez de vider le cache de l'application via les paramètres de votre appareil.

### J'ai perdu mes données enregistrées

Les données sont stockées localement sur votre appareil. Si vous avez désinstallé l'application ou effacé ses données, le contenu local peut ne pas être récupérable. Si vous aviez activé les sauvegardes de l'appareil, vous pourrez peut-être restaurer les données via les paramètres de sauvegarde et de restauration de votre appareil.
